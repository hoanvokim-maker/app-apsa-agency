Gửi báo giá qua Outlook

Điền sẵn tiêu đề, nội dung và file Excel của báo giá — chọn một trong hai cách gửi bên dưới.

1 chạm (máy Mac của Harris): tải file Excel rồi Outlook tự mở thư mới đã đính kèm sẵn, sửa thoải mái, chỉ việc bấm Send. Cần app APSA Mail Helper đã cài trên máy.
Tự đính kèm tay: tải file Excel + Outlook mở thư soạn sẵn; đính kèm bằng → Recent (2 cú nhấp) — máy nào cũng chạy.
Tải .eml: file mail đã kèm sẵn Excel. Windows mở ra là thư nháp sửa được; macOS mở chỉ đọc (muốn sửa thì kéo file vào thư mục Drafts của Outlook hoặc bấm Forward).
