APSA Slide Tracking — Cách gửi data từ trang web khác

1. Gửi 1 lượt xem slide (không cần API key)

fetch('https://manage.apsa.agency/api/tracking-api.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    project:      'Breztri Launch 2026',
    user_name:    'BS. Nguyễn Văn A',
    hospital:     'BV Nhân dân Gia Định',
    started_at:   Date.now(),   // hoặc '2026-07-12 14:30:00' — bỏ trống = giờ hiện tại
    slide:        '5',
    view_seconds: 12.5
    // ip: không cần gửi — server tự lấy IP người xem
  })
});

2. Gửi nhiều record 1 lần (khi kết thúc phiên xem)

fetch('https://manage.apsa.agency/api/tracking-api.php', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify([
    { project: 'Breztri Launch 2026', user_name: 'BS. A', hospital: 'BV X', slide: '1', view_seconds: 8,  started_at: 1780000000000 },
    { project: 'Breztri Launch 2026', user_name: 'BS. A', hospital: 'BV X', slide: '2', view_seconds: 15, started_at: 1780000008000 }
  ])
});

3. Gửi tự động khi người dùng rời trang (khuyên dùng)

// navigator.sendBeacon gửi được cả khi tab đang đóng
const data = JSON.stringify({
  project: 'Breztri Launch 2026',
  user_name: 'BS. A',
  hospital: 'BV X',
  slide: currentSlide,
  view_seconds: (Date.now() - slideStartTime) / 1000,
  started_at: slideStartTime
});
navigator.sendBeacon(
  'https://manage.apsa.agency/api/tracking-api.php',
  new Blob([data], { type: 'application/json' })
);

4. Xem data đã lưu (cần API key — chỉ dùng nội bộ)

fetch('https://manage.apsa.agency/api/tracking-api.php?project=Breztri%20Launch%202026&from=2026-07-01&to=2026-07-31', {
  headers: { 'X-API-Key': 'API_SECRET_CỦA_BẠN' }
}).then(r => r.json()).then(console.log);
